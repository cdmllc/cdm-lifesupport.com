CDM公式サイト
ドメイン: cdm-lifesupport.com
公開ファイル: TOP・事業・会社・採用等の30ページ＋404.html

更新方法:
本文: scripts/content.mjs
共通パーツ: scripts/ui.mjs / scripts/build-site.mjs
スタイル: assets/site.css
操作: assets/site.js

Node.js（追加パッケージ不要）で実行:
node scripts/build-site.mjs
node scripts/validate-site.mjs
node --check assets/site.js

生成されたHTMLとsitemap.xmlを、ソースと一緒にコミットしてください。
公開時にビルドは不要です。JavaScriptが無効でも本文と通常のリンクは利用できます。
お問い合わせはメールアプリでの送信方式です。送信API・フォーム受信サービスは使用していません。

掲載情報の確認事項:
資本金、従業員数、顧客名、実績数値、認証・資格は未確認のため掲載していません。
求人の報酬・稼働例は既存の公開情報を継承し、最終条件は面談で提示する旨を明記しています。
CRM画像はデモ表示です。契約仕様や実績ではなく、機能・利用・保守条件は個別の提案で確認します。

GitHub Pagesで公開する場合:
1. GitHubで公開リポジトリを作成
2. index.htmlをアップロード
3. Settings → Pages → Deploy from a branch → main / root
4. Custom domainに cdm-lifesupport.com を設定
5. ドメイン管理会社のDNSでGitHub Pagesの指定レコードを設定

※DNSの値はGitHubの現在のPages画面に表示されるものを使用してください。
