紹介された、その日から

顧客管理を、
毎日の動きに合わせる。

例えば、紹介を受けた見込み客に提案して、成約後に紹介者へ報告する仕事。CDM BASEでは、次のように情報を残していきます。

  1. 顧客と紹介元を登録する

    顧客の名前・連絡先と、紹介してくれた人を残します。LINEの表示名も登録して、誰と話しているかを確認しやすくします。

  2. 案件と次の対応を決める

    案件の状況を更新し、「見積もりを送る」「紹介者に経過を報告する」などのタスクに期限と担当をつけます。

  3. 入金予定と紹介料を確認する

    成約後は入金予定を確認。紹介者・代理店との取り決めに合わせた手数料を管理します。

  4. お礼・報告をして、次につなげる

    紹介元と案件の経緯を見返して連絡します。連絡・報告は担当者が行います。自動で紹介が増えることを保証するものではありません。

選び方・向いている人

顧客管理システム（CRM）とは何ですか？

顧客の連絡先だけでなく、対応の経緯・案件・担当者・次の対応をまとめて管理する仕組みです。CDM BASEは、その中でも紹介元と顧客のつながりを残し、紹介営業でのお礼・報告・案件管理を続けやすくすることを目的にしています。

個人事業主や1人でも顧客管理ツールは必要ですか？

必要かどうかは人数より、管理したい内容で判断します。連絡先の一覧だけなら表計算でも対応できます。誰の紹介か分からなくなる、次の連絡を忘れる、案件と入金予定が別々になるといった困りごとがあれば、CDM BASEの画面で実際の流れを試してください。

Excel・スプレッドシートからCRMへ変える目安は？

同じ顧客の紹介元・案件・履歴・次の対応を複数の表で探すようになったときが、比較する目安です。件数だけで判断せず、二重入力、連絡漏れ、担当者しか経緯を知らない状態が起きているかを確認します。

無料CRMと有料CRMは何を比較すればよいですか？

人数や機能の上限に加えて、紹介関係の見え方、移行作業、初期設定、運用相談にかかる手間と費用を比較します。CDM BASEは有料サービスで、専用環境と初期設定を提供します。面談や取り込み代行の範囲はプランにより異なります。

どんな業種に向いていますか？

紹介や継続的な顧客対応がある仕事を想定しています。例えば保険代理店、士業、リフォーム、フリーランスの営業などです。業種名だけで適合を決めず、顧客・紹介元・案件・紹介料をどう管理したいかをデモで確認します。

大規模な営業組織や大量のメール配信にも向いていますか？

複雑な承認経路や細かな組織権限、大量配信などが主目的なら、その要件に合うSFAやマーケティングツールも比較してください。CDM BASEは紹介営業の顧客・案件・次の対応をつなぐ用途を中心にご案内しています。

紹介営業と日々の使い方

紹介元・紹介者と顧客を一緒に管理できますか？

できます。顧客と紹介元を登録し、紹介ツリーで誰から誰へつながったかを確認できます。案件の経緯を見返しながら、お礼や報告をする相手を確認します。

顧客管理と案件管理を一つにできますか？

CDM BASEでは、顧客の連絡先や紹介元に加え、案件の状況、売上・粗利、入金予定、次の対応を管理できます。連絡先の一覧と案件の表を別々に探す手間を減らすための仕組みです。

LINEと連携してトーク履歴を自動で取り込めますか？

このLPで案内するLINE関連の機能は、顧客情報にLINEの表示名を登録して確認する機能です。LINEのトーク履歴の自動取り込みや、自動送信を標準機能として案内しているものではありません。必要な連携がある場合は、契約前に対応範囲を確認します。

紹介料や代理店ごとの手数料も管理できますか？

紹介者や代理店ごとに、1件あたりの金額や売上に対する割合など、取り決めに合わせた手数料を管理します。対象の人数や計算方法を伺い、対応範囲を事前に確認します。実際の振込を自動で行うという意味ではありません。

次の連絡や紹介者への報告を忘れないようにできますか？

次の連絡・お礼・報告を、期限と担当者をつけたタスクとして残せます。期限が近いものや過ぎたものを確認して、担当者が連絡します。

入金予定や未入金も確認できますか？

案件ごとの入金予定と、未入金の状況を確認できます。月別の売上・粗利の見込みも確認できます。銀行の入金と自動で照合する機能を案内しているものではありません。

スマホからも使えますか？

使えます。デモではスマホでの閲覧や記録の流れも確認できます。使いたい端末で、入力する項目や日常の作業が無理なくできるかをお確かめください。

移行・設定・サポート

今のExcelの顧客データを移せますか？

取り込み代行は、2026年11月30日までのスタンダードに1,000件まで、プレミアムに件数上限なしで含まれます。ライトは個別にご相談ください。12月1日からのライトのExcel取込代行は別途見積もりです。項目・重複・データの状態を確認して進めます。

パソコンが苦手でも導入できますか？

専用環境の用意と初期設定を代行します。操作が合うかは無料の画面見学で確認できます。2026年12月1日からのミニは、標準画面の社名・ロゴ・項目名・ステータス名の設定が対象で、コードの変更は含みません。

導入後に使わなくならないか心配です。相談できますか？

11月30日までの3プランと12月1日以降のライトには、担当者との毎月の定例面談を含みます。営業が止まっている所を確認し、運用を見直します。12月以降のミニには定例面談を含みません。紹介営業フルサポートには岩男の月2回の伴走を含みます。

データは他社と混ざりませんか？バックアップはありますか？

1社ごとに専用の環境を用意し、毎日自動で30日分のバックアップを保持する提供方針です。必要な権限、復元の進め方、データの取り扱いは導入前に確認します。

料金・契約・画面見学

CDM BASEの料金はいくらですか？

2026年11月30日までのライトは月10,000円、初期30,000円の記念価格です。12月1日からはミニが月5,000円・初期20,000円、ライトが月10,000円・初期50,000円、紹介営業フルサポートが月50,000円・初期200,000円です。すべて税別。初期費用・人数・支援内容・最低契約期間を合わせて比較してください。

3人で使う場合の料金は？

12月1日以降のミニを3人で月払いする例は、月5,000円＋追加2名分2,000円＝月7,000円、初期20,000円です。初回は27,000円（税別）、消費税10%込み29,700円です。ミニは3名まで利用可能ですが、3名分込みではありません。月払いは最低3か月です。

最低契約期間や解約時の費用はありますか？

月払いは、ミニ・ライトと11月30日までのスタンダード・プレミアムが最低3か月、紹介営業フルサポートが最低6か月です。期間内に解約しても最低契約期間の最後の月までの利用料をお支払いいただきます。別の解約金はありません。年払いは12か月です。

年払いや銀行振込はできますか？返金はありますか？

紹介営業フルサポート以外は年払いを選べ、12か月分を10か月分の料金で利用できます。月払いはカード（Stripe）、年払いはカードまたは銀行振込です。振込期限は請求書発行から3営業日以内で、振込手数料はお客様負担です。初期費用・年払いの支払済み料金は返金せず、月額の日割り返金もありません。

無料で試せますか？契約前に画面を見たいです。

無料の画面見学で、架空データのデモを確認できます。見学は約30分ですが、話が前後するため1時間枠を予約してください。無料プランや無期限の無料トライアルではありません。見学しただけで契約する必要はありません。

画面見学には何を用意すればよいですか？

今の顧客管理の方法と、困っている作業を一つ教えてください。Google Meetでお顔を見ながらお話しするため、カメラONをお願いしています。個人情報を見せなくても、匿名の例で流れを確認できます。

希望の予約日時が空いていない場合は？

公式LINEからお問い合わせください。日程を調整します。画面見学では、実際の画面を見ながら必要かどうかを判断してください。
